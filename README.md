Este repositório é dedicado ao armazenamento e organização de todos os materiais de estudo, exercícios práticos e entregas da disciplina de **Banco de Dados (PBD)**, cursada no 2º semestre de Análise e Desenvolvimento de Sistemas (ADS). 

O repositório abrange conceitos teóricos e aplicações práticas em duas das principais vertentes de armazenamento de dados: bancos de dados relacionais (**MySQL**) e bancos de dados orientados a documentos/NoSQL (**MongoDB**).
